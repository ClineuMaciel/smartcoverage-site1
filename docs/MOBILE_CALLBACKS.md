# Mobile call routing and callbacks

ZIP input, change, blur, Get started, page restoration and visibility restoration now refresh the server-owned call policy. Responses are sequence-checked so an older initial request cannot erase a newer ZIP lookup. UUID creation falls back for browsers without crypto.randomUUID. Office calls still require a verified TN/MS ZIP and Monday–Friday 9 AM–4 PM America/Chicago, including DST. No other states or closed hours receive the office phone link. Calls to approved buyers still require their configured state, hours and approval checks.

The unavailable Call Now button opens a callback form. The visitor explicitly submits their name, phone, ZIP, needs, coverage and separate service-callback permission. No phone number can be obtained merely by tapping a link. A direct tel link does not establish that a call connected. Clicking a live call link records an in-memory client attempt timestamp only; it is retained by the server only if that visitor later submits the callback form. Opening the callback form records a distinct client intent timestamp. Neither establishes a completed phone call. Abandoned, unsubmitted numbers are not captured.

POST /.netlify/functions/callback stores the server receipt time, client intent/attempt/request times (labelled client-provided), exact service permission/version/hash, server IP/user agent, insurance needs and route in LeadEvidence. Additional callback fields are in traffic_json with request_type=callback. It uses the existing Google Sheets ID/service account without new secrets. Tests and opt-outs remain withheld. Valid same-ID retries return the prior receipt. Sheets' read-then-append duplicate detection is best effort under concurrency, not a transactional lock.

The scheduled Sales List projection includes accepted callback evidence, with needs and attempt data in Source layout and a CALLBACK ONLY — no buyer sale review status. The callback checkbox is not buyer-marketing consent, and no buyer delivery occurs. TN/MS callback requests go to office or office_callback depending on hours. Other states await callback review; callback availability and qualification are not guaranteed. No automatic outbound phone calls, SMS, emails, or staff notifications are implemented. Staff must monitor/filter Sales List and use verified provider reports for completed-call accounting.

Outside office hours, the button should open the callback form. A permitted real submission should appear immediately in LeadEvidence and within the next successful five-minute sync in Sales List. A System Test submission is intentionally excluded from Sales List. Existing form submissions remain on the original lead endpoint.
